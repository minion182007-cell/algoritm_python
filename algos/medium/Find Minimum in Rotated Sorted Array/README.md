# 153. Find Minimum in Rotated Sorted Array

🟠 Medium · [Задача на LeetCode](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)

## Условие

Массив из `n` различных чисел был отсортирован по возрастанию, а потом повёрнут от 1 до `n` раз. Например, `[0,1,2,4,5,6,7]` может стать `[4,5,6,7,0,1,2]`. Нужно найти минимальный элемент.

## Решение 1: сортировка

[solution.py](solution.py)

Сортируем копию массива через `sorted()` и берём первый элемент. Это и есть минимум.

- **Время:** O(n log n) на сортировку.
- **Память:** O(n) на отсортированную копию.

## Решение 2: бинарный поиск

[solution_binary_search.py](solution_binary_search.py)

После поворота массив состоит из двух отсортированных частей, и минимум стоит в начале второй части. Ищем его бинарным поиском:

1. Берём границы `left = 0` и `right = n - 1`.
2. Смотрим на средний элемент `nums[mid]` и сравниваем его с последним `nums[right]`.
3. Если `nums[mid] > nums[right]`, середина в первой (большей) части, и минимум правее: `left = mid + 1`.
4. Иначе середина во второй части, и минимум в ней или левее: `right = mid`.
5. Когда `left == right`, это и есть индекс минимума.

Пример для `[4,5,6,7,0,1,2]`:

| left | right | mid | nums[mid] | nums[right] | Куда идём |
|------|-------|-----|-----------|-------------|-----------|
| 0 | 6 | 3 | 7 | 2 | 7 > 2, вправо: `left = 4` |
| 4 | 6 | 5 | 1 | 2 | 1 ≤ 2, влево: `right = 5` |
| 4 | 5 | 4 | 0 | 1 | 0 ≤ 1, влево: `right = 4` |
| 4 | 4 | | | | `left == right`, ответ `nums[4] = 0` |

- **Время:** O(log n), каждый шаг отбрасывает половину массива.
- **Память:** O(1).

Именно такую сложность просят в условии.
